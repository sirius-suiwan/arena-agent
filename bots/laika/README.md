# Laika（复刻）

A separate JSON Lines bot for Arena Agent. Entry point: `bots/laika/bot.js`. Its policy is an adaptation of [Killfield's Laika](https://github.com/Cichlider/killfield/blob/0ccc4ab15fa9888687e743574e0258260ee00e77/engine/src/laika.rs), pinned at `0ccc4ab15fa9888687e743574e0258260ee00e77`. The [upstream MIT license and its scope](https://github.com/Cichlider/killfield/blob/0ccc4ab15fa9888687e743574e0258260ee00e77/LICENSE) are reproduced in [LICENSE](LICENSE).

The port adapts goal competition with incumbent decay, aggression budget, short-range chase and low-ammo retreat, wall recovery, and incoming-trajectory checks. It uses Arena Agent's observed grid, projectile velocities, own ammo, and weapon fields; no access to hidden engine state. Shallow geometric shot prediction, a fixed candidate fan, deterministic goal tie breaking and a bounded avoidance search replace upstream game-specific geometry, randomness and action stack. It deliberately does not reproduce historical implementation bugs. It is neither the original Sublab AI nor a bit-for-bit port of the Killfield bot, and no original Tank Trouble source or assets are included.

```sh
node apps/cli/arena.js run --seed 12 --score-to-win 1 \
  --bot-a laika --bot-b gpt-dots
```

Classic uses the referee's observation profile for speed, reverse speed, turn size and tick timing. The adapter respects the configured live-shell limit and fresh presses, holds a charged Gatling until empty unless dodging, and steers an active RC missile through the normal turn input. Missing or invalid profiles produce a neutral action. The Killfield-derived pursuit/retreat/aim priorities are unchanged. Movement uses [Robocode community precise prediction and wall smoothing](https://book.robocode.dev/movement/advanced-evasion/wave-surfing-implementations.html) as a conceptual reference, not copied code. The Arena implementation turns toward a reachable cell center before cutting a tight corner, picks a bounded local escape when blocked, and tests forward, reverse and turn-then-go motions against timed, swept projectile paths. It models rounded wall reflections and point-laser reflections and an active Death Ray's observed path; homing/RC direction changes, hits on other tanks and unobserved projectiles are not predicted. An ordinary action is preserved when the planned path is clear. All of this runs in the Laika bot process without reading any other seat's actions.
