# Tank Trouble arena rules v1

An independent implementation of the maze-and-ricochet mechanics, not the original Flash code. A match is one round between exactly two tanks.

- **Simulated time:** 60 ticks per game second. State starts at tick 0. The actions supplied for an observation at tick N produce state and events for tick N+1. GUI frame rate and CPU time do not change game time.
- **Arena:** 64 px grid cells, default 8 × 6. Each round's seed controls a connected randomized maze, additional loop openings, which player occupies each opposing corner, and pickup placement/ties. Coordinates are in pixels; +x is right, +y is down; angles are radians, positive clockwise from +x. Wall line segments are axis-aligned.
- **Action:** `{ "throttle": 1, "turn": -1, "fire": false }`. Throttle −1/0/+1 reverses/stops/advances; turn −1/0/+1 turns counterclockwise/none/clockwise; fire is a per-tick request. Turning (0.06 rad/tick) precedes movement (2.2 px/tick); the body determines the fire direction. Tanks are 12 px radius circles. Wall penetration cancels the move but not the turn. If candidate tank poses overlap, both tank moves are canceled. A stopped action does not preserve the last movement.
- **Shells:** 3 px radius, 6 px/tick, maximum five live shells per owner, 24 tick normal firing cooldown. Shells are swept against wall faces and endpoints and reflect; a perpendicular simultaneous corner reverses both components, wall contact wins a tie with tank contact. Shells do not collide with one another. A new shell cannot hit its owner until it exits the hull collision radius or ricochets. Shells expire after 300 advances, including the spawn tick. An eight-bounce ceiling per tick expires degenerate shells. Tanks are sampled at their post-move positions for shell collisions. Combat impacts are gathered before damage is applied; for multiple hits on a tank with a shield, the oldest shell in that tick consumes it.
- **Pickups:** When enabled, spawn every 360 ticks by default, up to four present. Candidates are unoccupied cell centers at least 30 px from live tanks. A shield absorbs one hit (no stacking); rapid-fire halves cooldown for 240 ticks after acquisition (a new pickup renews it). Tanks collect within 20 px after combat. Closest live tank wins; ties use the seed, never process reply order.
- **Result:** Last living tank wins. Two deaths in the same tick are a draw. If both survive the configured time cap, the game draws by timeout (default 3,600 ticks / 60 game seconds). Terminal states are not advanced again.
- **Observation:** Full map and visible game state for both bots, including tanks, shell owner/position/velocity/lifetime/arming, pickups, and the receiving player ID. RNG state and sequence counters stay in the authoritative game state.
- **Config:** `cols` 4–16, `rows` 4–12, `maxTicks` 1–36,000, `pickupInterval` 1–3,600, `pickups` boolean; unknown keys rejected.
- **Reproduction:** Use the same implementation version/config/seed/player order and accepted actions, in the same runtime. Wall endpoint geometry uses floating point; no cross-runtime bit-identical guarantee.
